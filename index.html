wallcast

live

paint colour visualiser. photograph a room, repaint the walls.

semantic segmentation running entirely client-side: segformer executes in-browser through onnx runtime via transformers.js, on webgpu where an adapter is available and wasm otherwise, so images are never uploaded. mask post-processing — morphological open and close, connected-component filtering, douglas-peucker contour simplification — is implemented against typed arrays. recolouring applies the target hue and saturation while rescaling luminance against the region mean, preserving the original shading.

  • react
  • transformers.js
